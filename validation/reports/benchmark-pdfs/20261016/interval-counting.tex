\reporttitle{Interval counting verification}{Genesis/Python read-end overlap counts and bedtools coverage}
\begin{abstract}Across 160 evaluated library/method/repetition records, independent read-end counts have zero mismatching regions. The records contain 892,528 region evaluations, including repeated regions across methods and technical runs. This verifies arithmetic under the declared overlap convention, not biological accuracy or relative speed. We would retain the current counter and its independent checks.\end{abstract}
\section*{Setup}
\textbf{Comparisons.} The benchmark counts retained primary read-end spans in zero-based half-open peak intervals using Python and bedtools 2.31.1 coverage. Paired ends count independently. Fragment-level FRiP is a different quantity and is not used as a counting-equivalence target.

\textbf{Scoring.} A mismatch is a region whose integer overlap counts differ. Any shared base counts as overlap; no fractional NH weighting is introduced. Denominators count evaluated region instances, not distinct regulatory elements or biological replicates.

\textbf{Missing values.} A missing or unevaluated count is not zero. Any unavailable records remain in the exported counting table with their status and reason; the denominator above includes only records explicitly marked OK.

\textbf{Publication scope.} These checks cover the benchmark's independent integer read-end overlap calculation. They do not certify all production quantification modes, NH fractional weighting, spliced-block conventions, or coverage integration by transitivity.

\section*{Open issues}
\begin{itemize}
\item Repeated evaluation of a fixed peak set is not independent biological validation.
\item Span-based overlap should not be generalized to spliced exon-block counting.
\item No matched standalone runtime advantage is established.
\end{itemize}
\section*{Recommendation}
We would retain exact arithmetic tests and avoid choosing a counter by unmatched timings.

\begin{enumerate}
\item Define a counting-only test with identical interval ordering, BAM cache conditions and units.
\item Measure time and process memory separately from conversion and file staging.
\end{enumerate}
\section*{Appendix: Methods}
We summarize recorded results without rerunning biological processing. The main Arabidopsis matrix uses seeded nested raw-template subsets (seed 60141), three fresh technical repetitions at the 1-million cap and one at the 5-million cap. Actual counts replace requested caps for short libraries. DAP retains primary mapped reads including MAPQ 0; ATAC selects proper primary pairs with both mates MAPQ at least 30, excludes MAPQ 255, organelles and marked duplicates. Biological identity is preserved. Source files are SHA-256 checked against the accompanying catalog; evidence snapshot revision ed1c50b8e4b5 includes the October 13 to 16 records. Completed local reference assessments are separately identified in that catalog.
